# COBO Compliance Boards 3D Configurator

A 3D board builder for complianceboards.com. Customers pick a size, board color, edge-banding color and cap finish, and see it update live (front, angle, and back views). It is built from the same dimensions as the Fusion 360 master model, so what they see matches what you build.

No build step. It is plain HTML + JavaScript, so it runs on GitHub Pages as-is.

## What is in this folder

| File | What it does |
|---|---|
| `index.html` | The page and all the styling. Edit colors/fonts in the `<style>` block at the top. |
| `js/config.js` | **The file you will edit most.** Sizes, prices, colors, finishes, hardware dimensions, Shopify variant IDs. |
| `js/main.js` | The 3D scene and behavior. You should not need to touch this. |
| `tools/build_laminates.py` | Turns a folder of Wilsonart swatch images into the laminate library (see below). |
| `data/laminates.json`, `textures/` | The laminate library the picker reads (generated by the tool above). |
| `vendor/` | Three.js and Google's model-viewer (for phone AR), both open source, included so the page does not depend on any CDN. |
| `shopify/cobo-configurator-embed.liquid` | Paste into Shopify to embed the viewer and wire up add-to-cart. |

## Preview it on your computer

Double-clicking `index.html` will not work (browsers block the 3D files when a page is opened straight from disk). Instead:

1. Open a terminal in this folder (in Windows File Explorer: click the address bar, type `cmd`, press Enter).
2. Type `node tools/serve.js` and press Enter. (Needs Node.js, which is already on Justin's PC. If you have Python instead, `python -m http.server 8000` does the same job.)
3. Open http://localhost:8000 in your browser. Leave the terminal window open while you look; close it when done.

## Put it on GitHub Pages

1. Create a new GitHub repo named `cobo-configurator` (public is simplest).
2. Upload everything in this folder to the repo root (so `index.html` is at the top level).
3. In the repo: Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. After a minute the viewer is live at `https://YOUR-GITHUB-USER.github.io/cobo-configurator/`.

This is already done: the repo is https://github.com/jcolli40/cobo-configurator and the live viewer is https://jcolli40.github.io/cobo-configurator/.

Updating later: edit `js/config.js` on GitHub (pencil icon) and commit. The live page updates in about a minute.

Before pushing changes to `js/main.js` or `js/config.js`, run `node tools/stamp-version.js`. It gives those files a new `?v=` in their links so phones can't mix a fresh page with an old cached script (GitHub Pages caches each file for about 10 minutes, which can leave the board blank right after an update). If the builder ever fails to start, the page shows a Reload message instead of a blank board.

## Put it on Shopify

1. In Shopify: Online Store → Pages → Add page (e.g. "Design Your Board").
2. Add a **Custom Liquid** section (or edit the page HTML in your theme's page template).
3. Paste in `shopify/cobo-configurator-embed.liquid` (it already points at `https://jcolli40.github.io/cobo-configurator/`).
4. Save. The viewer appears inline, and "Add to cart" adds the chosen quantity of the matching variant to the Shopify cart (customers stay on the page; the cart preview updates).

You can also link straight to a preset, handy from product pages:
`.../cobo-configurator/?size=12x24&color=Forest%20Green&edge=Yellow&finish=chrome&orient=landscape`

## Three versions

- **v1** (main link): one panel with every option.
- **v2** (`/v2/`): size first, then **Standard board** (stock colors, priced) or **Custom board** (laminate, any color, printing; quoted). Fewer big cards; small choices are rows with toggles and eye icons (show/hide in the preview).
- **v3** (`/v3/`): size first, then every option with its price ("Included" or "+$X"). Options are priced and go in the cart; only custom sizes are quoted. Upcharge amounts are placeholders in `UPCHARGES` in `js/config.js`.
- **v4** (`/v4/`): guided, photo first. A full-screen start asks for a photo of the wall; we count the documents, size a board, read the wall color and suggest looks to swipe through (the board stays put). "Customize this look" (or tapping a part of the board) opens the v1 options panel. The looks and how they're ranked are `STYLES` in `js/config.js`. `?step=styles` skips the photo; `?scan=demo` runs the example photo.

- **v5** (`/v5/`): Auto-suggest. Three full-screen steps over the live 3D board, with Back and Skip: welcome, snap your wall (a live camera on phones; the Shopify iframe needs `allow="camera"`), then our picks to swipe through. The options panel has an Auto-suggest button, every option as its own card with its upcharge (`UPCHARGES` in `js/config.js`, one amount or one per size), the edge and sample-certificate rows, and My wall (the photo, each document found and its guessed size, your own documents). No logo or background image. `?step=snap` opens the camera step.

All five share one engine (`js/main.js`) and one page. **Edit `index.html` only**, then run `node tools/make-versions.js`, which writes `v2/` to `v5/index.html`. Before pushing, also run `node tools/stamp-version.js`.

Rooms and lighting presets live in `ENVIRONMENTS` (config.js), with the wall textures drawn in `js/env.js`. Popular boards are in `PRESETS`, and volume discounts in `DISCOUNTS` (placeholders; set the same tiers as an automatic discount in Shopify).

## Other features (and where to tweak them)

- **Sample certificates:** the viewer fits as many 8.5×11 certificates as it can (clear of the edges and caps) and says how many fit. Customers can rotate them 90°. Sizes, spacing and certificate titles are in `SHEETS` in `js/config.js`.
- **Logo on board:** customers upload a logo (PNG/SVG/JPG) and choose a layout (single, grid, brick, half-drop, honeycomb, checkerboard, mirrored, alternating, scatter) with sliders for width, spacing, rotation, opacity and position. A logo board is always a quote request. Slider ranges are in `ARTWORK` in `js/config.js`.
- **Viewer background:** wall color swatches plus an optional background image with the same layout options. Preview only; it is not part of the order.
- **Quantity + cart preview:** inside Shopify, the page sends the real cart back into the viewer. Opened on its own, the cart is a pretend one for testing.
- **Phone AR ("View on your wall"):** shows only on iPhone/iPad (Apple Quick Look) and Android Chrome (WebXR). It uses Google's `<model-viewer>` (`vendor/model-viewer.min.js`) and places the board at real size. Add `?ar=1` to the URL to see the pop-up on a computer.

## Adding Wilsonart laminates (custom boards)

The configurator has a "Wilsonart laminate…" picker: customers can search by design number or name, filter by
Design Type / Color / Shade (and Cut / Match for woodgrains), and see the real pattern on the 3D board. Laminate
boards are custom-made, so choosing one switches the button to "Request a quote". Numbers that are not in the
library can still be typed in; they show a stand-in color and the number goes onto the quote.

Right now the library holds 13 real Wilsonart swatches (Ivory Terrene 5075, the Strata series, Java Cane, and more). Their Color and Shade tags are first-draft guesses and Design Type is still blank; fill in `laminates.csv` and re-run the importer to fix that. (That spreadsheet and the swatch images are not in this repo: they live in the Dropbox client folder at `COBO - Compliance Boards/_Web Configurator/Wilsonart/`.) To add more:

1. Put the swatch images in one folder. Start each file name with the design number: `5075.jpg`, or
   `5075_Ivory_Terrene.jpg` (Wilsonart's own download names like `5075_8x8-Ivory-Terrene.avif` also work; .avif, .jpg, .png and .webp are all accepted).
2. Optional but recommended: fill in `tools/laminates-template.csv` (number, name, design_type, color, shade, cut, match)
   and save it next to the images. This is what makes the filters work. Wilsonart's website filter lists show the
   exact wording to use; the spellings the picker expects are in `LAMINATE` at the bottom of `js/config.js`.
3. Run the importer (needs Python and `pip install pillow`):

       python tools/build_laminates.py my_swatches --csv my_swatches/laminates.csv

4. It writes `textures/thumb/`, `textures/full/` and `data/laminates.json`. Commit those to GitHub.

You can run it again any time with more images: it adds to the library (same number = replaced). Expect roughly 15 KB per thumbnail and 100–200 KB per
full texture, so the whole 1,187-design catalog is about 150–250 MB; that is fine for GitHub Pages but see the note
below.

**Tip for the full catalog:** if GitHub gets heavy, lower `FULL_PX` in the importer from 1024 to 768 and the
`tileIn` setting in `config.js` controls how large the pattern appears on the board (default: one swatch per 12").

You can also link straight to a laminate: `.../cobo-configurator/?size=24x36&lam=5075`

## Assumptions baked into the model (change in `HW` in `config.js` if wrong)

- Overall board thickness is 3/4" including the front and back laminate skins (0.03" each).
- Acrylic is 3/16", cut to exactly the board size with flush edges.
- The acrylic sits directly on the compliance sheets (no spacers); 1/16" is allowed for the stack of sheets between the board face and the acrylic.
- Four 1" aluminum caps, centered 1" in from each edge, each with an M6 × 1" stud into an M6 T-nut recessed into the back.
- Cap thickness is 1/4" (assumed).
- The aluminum z-clip is 1/16" thick, starts 3" below the top edge, and is 2" shorter than the board width on each side (1.5" on boards narrower than 12").
